# Contributing

PRs welcome for typos, clearer explanations, and additional verified YouTube/docs links.

## Guidelines

- Keep each topic readable in ~10 minutes.
- Do not invent YouTube or docs URLs — verify with YouTube oEmbed / a live HTTP check before adding.
- Match the existing topic shape (why it matters → core concepts → mental model → interview Qs → watch → further reading).
- Prefer AWS-first examples with short Azure/GCP callouts where useful.
- Use trailing-slash relative links between topics (`../03-ci-github-actions/`), not `.html`.

Open a draft PR against `main`. Thanks!
