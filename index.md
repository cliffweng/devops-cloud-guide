# DevOps & Cloud Guide

A practical, no-fluff guide for builders who want to ship side projects that actually run in production — and walk into SWE/SRE/platform internship interviews knowing how the pieces fit together.

## How to use this guide

- Each topic in the left nav is a **standalone page you can read in ~7–9 minutes**.
- Every page follows the same shape: **why it matters**, **core concepts**, a **mental model**, **interview questions** with brief answer keys, and a short **watch list** of verified YouTube videos.
- Topics are ordered roughly: your day-1 box → shipping code → cloud fundamentals → interview capstone. You can read them in order, or jump straight to the topic you need.
- This guide is **AWS-first**, with short Azure/GCP callouts where the equivalent service is worth knowing by name.
- Nothing here requires a backend, an API key, or a login — it's just reading.
